# 文輕小站

**文輕小站**是一個專注於中文輕小說創作的展示與交流 APP，旨在降低新手創作者的門檻，提供隨身創作工具與乾淨舒適的創作體驗。

- 此專案最初為學生時期的畢業專題，包含 Figma Prototype 與電腦版展示網頁，後於 2025 年將原本的展示網頁重新改版 RWD 。

---

## 🎯 專案特色

- **自由創作**：推廣中文小說創作自由，降低新手門檻
- **隨身工具**：以手機取代紙本，隨時記錄靈感
- **優化體驗**：打造乾淨舒適的創作環境，鼓勵新手開始創作

---

## 🛠 技術棧

- Vue 3 + Vite + Tailwind CSS + Cloudinary

---

## 🏗 開發里程碑

| 年份 | 事件                                                         |

| 2022 | 專案發想與主題確立、使用者研究、資訊架構、問卷調查與市場分析 |
| 2023 | 完成使用者旅程規劃、線框圖、Mockup、Prototype（Figma 原型）  |

## 👥 開發團隊

- **視覺設計負責人**
  主要設計：寵物、社群、檔案統整線框圖
  其他工作：APP 內插圖、Logo 與海報

- **工程互動負責人**
  主要設計：人物關係圖項目線框圖
  其他工作：專案策劃、原型製作、網頁設計

- **媒體製作負責人**
  主要設計：大綱項目線框圖
  其他工作：影片剪輯、行政宣傳
